# 檸檬車市場模擬 The Market for "Lemons"

Akerlof (1970) 二手車市場的互動動畫：100 台二手車（50 台好車、50 台檸檬）、100 位買方，一期一期看資訊不對稱如何讓「爛車趕走好車」。

**線上版**：https://halcyone1234-ux.github.io/lemon-market-sim/

## 模型設定

- 好車 50 台：車主估價 50–100 萬；檸檬 50 台：車主估價 15–25 萬。
- 買方對每台車的估價都是車主的 1.5 倍（Akerlof 的 3/2），但看不出哪台是檸檬，只能按展示場的平均品質出價。
- 每期三步：買方出價 = 1.5 × 預期平均品質 → 估價高於出價的車主退出 → 展示場的車成交，買方發現買貴了、下期調低預期（調整速度 0.35）。
- 約 14 期收斂：價格停在 30 萬左右，展示場只剩 50 台檸檬，50 台好車全部退出。買方願為好車付 75–150 萬、車主只要 50–100 萬，卻一筆也沒成交。
- 「有認證：資訊對稱」對照組：買方看得見品質，100 台全部成交，底部直接比較兩種情境的交易利得（Akerlof 的 N/2）。

## 使用

單一 HTML 檔，無需安裝。下載 `index.html` 直接用瀏覽器開啟即可；上課可用「播放／下一期」逐期講解。
